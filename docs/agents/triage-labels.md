# Triage Labels

| Papel canônico    | Rótulo usado      | Significado                            |
| ---------------- | ----------------- | -------------------------------------- |
| `needs-triage`   | `needs-triage`    | Precisa ser avaliado                   |
| `needs-info`     | `needs-info`      | Aguarda informações adicionais         |
| `ready-for-agent` | `ready-for-agent` | Está especificado e pronto para agente |
| `ready-for-human` | `ready-for-human` | Requer implementação humana            |
| `wontfix`        | `wontfix`         | Não será realizado                     |

Quando uma skill mencionar um papel canônico, usar o rótulo correspondente desta tabela. Em arquivos locais, registrá-lo na linha `Status:`.
